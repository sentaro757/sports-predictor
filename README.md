# 승부예측 대시보드

야구·축구·농구 10개 리그의 일정, 결과, 뉴스, 부상, 영입·방출 소식을 모아서 경기 승부를 예측하는 웹 대시보드입니다.

| 종목 | 리그 | 데이터 출처 |
|---|---|---|
| ⚾ 야구 | KBO, MLB | 네이버 스포츠, ESPN |
| ⚽ 축구 | K리그1, 프리미어리그, 라리가, 분데스리가, 세리에A, 리그1 | 네이버 스포츠, ESPN |
| 🏀 농구 | KBL, NBA | 네이버 스포츠, ESPN |

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 리그를 처음 열 때는 과거 경기를 수집하느라 10~20초 걸리고, 그 뒤로는 캐시(`data/cache`)를 씁니다.

- `npm run check`: 모든 리그의 수집과 예측을 점검합니다. 리그 하나라도 실패하면 종료 코드 1로 끝나고, 일부 수집 실패나 오래된 캐시 사용 같은 경고도 출력합니다(대시보드 상단에도 표시).
- `npm test`: 코드 리뷰(REVIEW.md)에서 지적된 문제들의 회귀 테스트입니다.

기본적으로 **이 PC에서만** 접속할 수 있습니다(127.0.0.1). 같은 네트워크의 다른 기기에서 쓰려면 접속 토큰을 함께 설정하고, 첫 접속 주소에 `?token=...` 을 붙입니다.

```powershell
$env:HOST = "0.0.0.0"; $env:ACCESS_TOKEN = "아무도-모를-긴-문자열"; npm start
```

## 예측 방식

1. **Elo 전력 지수**: 경기 결과와 점수차로 팀 레이팅을 계산합니다. 사용하는 기간은 국내 리그 약 18개월, MLB·NBA 이번+지난 시즌, 유럽 축구 이번+지난 두 시즌입니다.
   - 시즌 구분은 ESPN의 시즌 정보, 국내 리그는 KST 날짜 기준 시즌 연도로 합니다. 새 시즌 첫 경기 전부터 레이팅을 평균 쪽으로 일부 되돌리고 폼을 비웁니다.
   - 축구 승격팀은 리그 평균보다 100점 낮게 시작합니다. 강등된 팀과의 지난 시즌 경기도 빠짐없이 포함합니다.
2. **홈 어드밴티지**: 종목별로 다르게 줍니다.
3. **축구 승/무/패**: Elo 차이를 기대 득점 차이로 바꾸고 포아송 분포(Dixon-Coles 저득점 보정)로 확률을 냅니다. 리그별 평균 득점과 보정값은 과거 경기의 로그 손실이 가장 낮도록 맞춥니다.
4. **최근 폼**: 최근 5경기 성적을 반영합니다.
5. **부상자**: MLB, NBA는 ESPN 부상자 명단을 씁니다. 같은 선수는 한 번만 세고, 복귀 예정일이 3주 넘게 남은 장기 결장은 이미 성적에 반영된 것으로 보고 가중치를 낮춥니다.
6. **뉴스 신호**: 최근 3일 기사에서 부상·결장·감독 경질은 악재로, 복귀·합류는 호재로 봅니다. "삼성전 앞둔 LG 주전 부상"처럼 두 팀이 나오면 키워드 바로 앞의 팀(LG)에만 반영하고, "복귀 불발"이나 "not available" 같은 부정문은 악재로 뒤집습니다. 같은 사건을 다룬 기사는 한 번만 세고, 부상 명단이 있는 리그는 기사 속 부상을 따로 세지 않습니다.
7. **시범경기**: NBA·MLB 시범경기는 표시를 붙이고 확률을 50:50 쪽으로 절반 당깁니다.
8. **사후 검증**: 경기마다 "그 경기 직전의 Elo+홈 어드밴티지로 예측했다면 맞혔는지"를 기록해 적중률과 로그 손실을 보여줍니다. 폼·부상·뉴스 보정은 과거 시점의 기사·부상 기록이 없어서 검증에 포함되지 않습니다(화면에도 "Elo+홈 백테스트"로 표시). 축구 확률 보정값은 평가하는 시즌 이전 경기로만 맞춥니다.

종목별 파라미터는 `src/config.js` 의 `MODEL` 에서 바꿀 수 있습니다.

## AI 뉴스 분석 (선택)

API 키를 설정하면 경기 상세 화면에 **AI 분석 실행** 버튼이 생깁니다. Claude가 부상, 이적, 팀 기사의 내용을 읽고(예: 빠진 선수가 주전인지, 선발투수가 누구인지) 통계 확률을 보정한 뒤 이유를 한국어로 설명합니다.

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."
npm start
```

- 기본 모델은 `claude-opus-5-5` 입니다. 비용을 줄이려면 `$env:AI_MODEL = "claude-haiku-5-5"` 처럼 바꿀 수 있습니다.
- 같은 경기는 3시간 동안 다시 분석하지 않습니다(캐시).
- 비용 안전장치: 하루 최대 30회(`AI_DAILY_LIMIT` 으로 조정), 동시에 2건까지만 실행합니다.
- 기사 내용은 신뢰할 수 없는 외부 데이터로 표시해 전달하고, AI가 낸 확률은 통계 예측에서 결과별 ±15%p 안으로 제한합니다. 형식이 잘못된 응답은 한 번 다시 시도하고, 그래도 안 되면 통계 예측을 그대로 보여줍니다.
- AI가 요청을 거절하면 서버 쪽에서 다른 모델로 자동으로 다시 시도합니다(`fallbacks: "default"`).

## 팀 공식 홈페이지 뉴스 추가

구단 사이트마다 구조가 달라서 직접 스크래핑하면 쉽게 깨지므로, RSS/Atom 피드를 등록하는 방식으로 만들었습니다. `data/team-feeds.json` 에 리그 ID, 팀 ID, 피드 주소를 넣으면 해당 팀 뉴스에 "구단 공식" 표시와 함께 섞여 나옵니다. 팀 ID는 경기 상세 화면의 팀 이름 옆에 나옵니다.

```json
{
  "epl": { "359": "https://example.com/arsenal/news.rss" }
}
```

## 한계

- 국내 리그(KBO, K리그, KBL)와 유럽 축구는 공개된 부상자·이적 명단이 없어서 기사에서 자동으로 골라냅니다. 그래서 정확도가 MLB, NBA보다 낮습니다.
- 야구의 선발투수, 축구의 로테이션 같은 경기별 라인업은 통계모델에 들어가 있지 않습니다. AI 분석이 기사를 통해 일부를 보완합니다.
- 네이버와 ESPN의 공개 API는 공식 지원되는 API가 아니어서 예고 없이 바뀔 수 있습니다. 개인 용도로만 쓰고, 요청 빈도는 캐시로 낮춰 두었습니다.
- 예측은 참고용입니다.

## 구조

```
server.js            HTTP 서버와 API 라우팅
src/config.js        리그 목록과 모델 파라미터
src/sources/         naver.js, espn.js, feeds.js (데이터 수집)
src/model.js         Elo, 포아송(축구), 보정, 사후 검증
src/signals.js       뉴스 키워드 분류, 부정문 처리, 기사 대상 팀 판단
src/service.js       리그별 데이터 취합과 경기 상세
src/ai.js            Claude 분석 (선택)
public/              대시보드 화면
test/                회귀 테스트 (npm test)
```
